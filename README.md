# RENOVA – Renovation Management System

RENOVA is a full-stack web application designed to manage the complete home renovation process. It allows customers to submit and track renovation requests, view scheduled bookings, make payments and receive notifications, while administrators can manage renovation requests, bookings, payments and project statuses.

The application is built with React for the frontend, Java Spring Boot for the backend, MySQL for the database and JWT with Spring Security for authentication and role-based authorization. The complete application is containerized using Docker and Docker Compose.

## Tech Stack

- **Frontend:** React, Vite, JavaScript, React Router, Axios, CSS
- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA
- **Database:** MySQL
- **Authentication:** JWT
- **API:** REST API
- **DevOps:** Docker, Docker Compose, Nginx
- **Testing:** Postman
